# tapiceria-espinosa-madrid

Propuesta de rediseño **no oficial** para **Tapicería Espinosa** (Ciudad Lineal, Madrid), creada por Alex. Web actual: https://www.tapizadosespinosa.com/

- **Demo:** https://atilavg.github.io/tapiceria-espinosa-madrid/
- **Estructura:** `index.html`, `assets/css/styles.css`, `assets/js/main.js`, `assets/img/favicon.svg`, `.nojekyll` (GitHub Pages, rama `main`, raíz).
- **Intro:** scroll-scrubbing de `assets/intro.mp4`. Si el vídeo no existe, se muestra una animación en canvas que también avanza con el scroll. Prompts para generarlo en `PROMPTS-VIDEO.md`.
- **Aviso:** franja superior "Propuesta de rediseño no oficial — creada por Alex" y `<meta name="robots" content="noindex, nofollow">`.
- **Docs internos (excluidos con `.gitignore`):** `ANALISIS.md`, `MENSAJE.md`, `crear-repo.ps1`.
- **Publicar:** ejecutar `crear-repo.ps1` en PowerShell desde esta carpeta (requiere git y gh con sesión iniciada) y activar Pages en Settings → Pages → main / root.

Textos e ilustraciones propios; no se usan fotos ni logotipos del negocio.
